
# Padaemon

Padaemon is a solution to use a gamepad as a system-wide mouse input

## Features (for now)
- Left stick --> cursor movement
- Right stick --> scroll
- Button Cross, A or B --> Left click
- Button Square, B, or A --> Right click


## Requirements

### ---- System ----
- Linux (wayland)
### ---- Python ----
- pygame
- pydotool
just install them through the requirements.txt
### --- Hardware ---
- A gamepad (obv)
